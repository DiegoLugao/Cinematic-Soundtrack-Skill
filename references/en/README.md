# English reference guide

Use this directory with the English `SKILL.md` at the repository root.

## Start here

1. Read the root `SKILL.md`.
2. Copy `examples/example-plan.json` for a new production.
3. Study the [approved v11 recipe](approved-recipe-v11.md).
4. Choose layers using [roles, sounds, and key](roles-sounds-and-key.md).
5. Finish with [measurement and validation](measurement-and-validation.md).
6. Use [intro variations](intro-variations.md) when the approved recipe does not fit the song.

## Prerequisites

- Python 3.10 or newer for the included scripts.
- Python 3.11 in a separate environment for `audio-separator`.
- `ffmpeg` available on `PATH`.
- Python packages listed in `requirements.txt`.
- Music and sound files you own or are licensed to use.
