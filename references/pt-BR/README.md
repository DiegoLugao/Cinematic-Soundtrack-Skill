# Guia de referências em português

Use esta pasta com o arquivo `SKILL.pt-BR.md` da raiz.

## Por onde começar

1. Leia `SKILL.pt-BR.md`.
2. Copie `examples/plano-exemplo.pt-BR.json` para uma produção nova.
3. Estude a [receita aprovada v11](receita-aprovada-v11.md).
4. Escolha as camadas em [papéis, sons e tom](papeis-sons-e-tom.md).
5. Termine com [medição e validação](medicao-e-validacao.md).
6. Use [variações de intro](variacoes-de-intro.md) quando a receita aprovada não servir para a música.

## Pré-requisitos

- Python 3.10 ou mais novo para os scripts incluídos.
- Python 3.11 em ambiente separado para o `audio-separator`.
- `ffmpeg` disponível no `PATH`.
- Pacotes Python listados em `requirements.txt`.
- Arquivos de música e efeitos próprios ou licenciados para o uso pretendido.
